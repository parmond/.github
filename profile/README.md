### isosweep

Contour lines and filled contours from 2D grids, several times faster than
GDAL, VTK and ContourPy on a single CPU core, with closed, hill/hole-classified
curves and OGC-valid polygons. A commercial C library with a Python package and
a command-line tool: [isosweep.com](https://www.isosweep.com).

Every published figure is measured on dedicated bare-metal hardware and checked
by an automated audit against the raw samples.
[**isosweep-benchmarks**](https://github.com/parmond/isosweep-benchmarks) holds
the harness, specifications and audited results, so anyone can repeat the
measurements of GDAL, VTK, ContourPy, scikit-image and contour-rs.
